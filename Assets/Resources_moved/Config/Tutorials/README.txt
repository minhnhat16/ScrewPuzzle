README
=====
These are Unity ScriptableObject .asset templates for the 7-step tutorial flow.

IMPORTANT:
- Unity script GUIDs are project-specific.
- After importing, select each .asset and reassign the Script field to your TutorialStep / TutorialConfig script once.
- Then fix references if needed (Unity will update fileIDs).

Folder suggestion:
Assets/Tutorial/Steps/*.asset
Assets/Tutorial/Configs/TutorialConfig_Level1.asset
